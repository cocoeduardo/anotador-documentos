# Anotador Documentos

App de Mac de **Cocolab** para corregir PDF e imágenes: rectángulos, elipses, flechas, subrayador y textos, con exportación a PDF o PNG.

Aquí solo se publican las versiones de la app (el código no está en este repositorio).

## Instalar (solo la primera vez)

1. Entra en **[Releases](https://github.com/cocoeduardo/anotador-documentos/releases/latest)** y descarga `Anotador-Documentos-V….zip`.
2. Abre el zip y arrastra **Anotador Documentos** a la carpeta **Aplicaciones**.
3. Ábrela. Si macOS dice que no puede comprobar el desarrollador: ve a **Ajustes del Sistema › Privacidad y seguridad**, baja hasta el aviso de «Anotador Documentos» y pulsa **Abrir igualmente**. Solo hay que hacerlo una vez.

## Actualizaciones

La app mira sola si hay una versión nueva al abrirse (y una vez al día) y pregunta si quieres instalarla.
También: menú **Anotador Documentos › Buscar actualizaciones…**

Requisitos: Mac con Apple Silicon y macOS 14 o posterior.
